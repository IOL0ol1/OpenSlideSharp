Redistributed components
-------------------------------------------------------------------------------

1. OpenSlide and the libraries linked into it (openslide-bin)

   The native libraries tools/net10.0/any/runtimes/<rid>/native/libopenslide-1.* are builds of OpenSlide
   (https://openslide.org/) from openslide-bin (https://github.com/openslide/openslide-bin). OpenSlide is licensed
   under the GNU Lesser General Public License, version 2.1 (LGPL-2.1-only). The library of each platform statically
   links further components, each under its own license. The full license texts of OpenSlide and of these
   components, and VERSIONS.md with their versions, are in the licenses folder of that platform:

     licenses/openslide-bin/windows-x64/          runtimes/win-x64/native/
     licenses/openslide-bin/linux-x86_64/         runtimes/linux-x64/native/
     licenses/openslide-bin/linux-aarch64/        runtimes/linux-arm64/native/
     licenses/openslide-bin/macos-arm64-x86_64/   runtimes/osx-arm64/native/ and runtimes/osx-x64/native/

   OpenSlide's license text is licenses/openslide-bin/<platform>/OpenSlide/COPYING.LESSER.

   Source code: licenses/openslide-bin/openslide-bin.json names the openslide-bin build (binVersion) and its source
   tarball, openslide-bin-<binVersion>.tar.gz (source.url, with its sha256 in source.sha256). The tarball holds the
   source code of OpenSlide and of every component listed above, and the scripts that build these libraries from it.
   The same tarball is also attached to the OpenSlideSharp GitHub release of this package's version, tag
   v<package version> on https://github.com/IOL0ol1/OpenSlideSharp/releases, which keeps it after openslide-bin's
   nightly builds (https://github.com/openslide/builds) are removed. Check either copy by its file name and against
   source.sha256.

   The tool loads the library at run time. To use another build of OpenSlide 4.x, for example one built from that
   source, set the OPENSLIDE_LIBRARY_PATH environment variable to its full path.

2. SkiaSharp and Skia

   SkiaSharp (https://github.com/mono/SkiaSharp) is licensed under the MIT license, and the native libraries
   tools/net10.0/any/runtimes/<rid>/native/libSkiaSharp.* contain Skia (https://skia.org/), BSD-3-Clause, and further
   third-party code. See licenses/skiasharp/LICENSE.txt (SkiaSharp's license) and
   licenses/skiasharp/THIRD-PARTY-NOTICES.txt (the notices of the code in SkiaSharp's and HarfBuzzSharp's native
   builds).

3. OpenSeadragon and its scale bar plugin

   Written by openslide-sharp deepzoom -r for its HTML viewer. OpenSeadragon (https://openseadragon.github.io/) is
   licensed under BSD-3-Clause: licenses/viewer/LICENSE.openseadragon. The scale bar plugin
   (https://github.com/usnistgov/OpenSeadragonScalebar) is in the public domain (NIST):
   licenses/viewer/LICENSE.openseadragon-scalebar.
